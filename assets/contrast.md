## 抽帧指引

```bash
# 成片位置（按各片台账核对）：<产线目录>/<slug>/out/final.mp4
# 普通抽帧（秒）：
ffmpeg -ss <t> -i <成片> -frames:v 1 /tmp/qa-<slug>-<t>.png
# 帧级精抽（验白闪/闪帧等单帧现象，禁用 -ss 输入定位，见 field-notes 2026-10-25 条）：
ffmpeg -i <成片> -vf "select='between(n,<a>,<b>)'" -vsync 0 /tmp/qa-%02d.png
```

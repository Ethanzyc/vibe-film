# 对标逆向与自查（Step 3 + Step 6）

审美是比出来的，不是规则推出来的。自查循环里必须有一张对标帧，否则「太空了」第一轮就抓不出来。

## 对标逆向（写码之前）

1. 取 4-6 张**同功能**对标帧（钩子/介绍卡/密度镜头/稀疏帧各一），来源：自建帧库或对标成片抽帧
2. 逐张 Read（真的看图），每张写出「这帧为什么成立」的可执行结论，例如：
   - 密度=每个元素都有语义：30+ 标签没有一个是装饰 → 执行：中景元素必须携带信息
   - 色彩随情绪在帧内编码：白→琥珀→红就是叙事梯度 → 执行：全片情绪线可在单帧内感知
   - 帧内 UI 仿真制造真实感：微信绿气泡+等宽时间戳 → 执行：微文案用界面语言（时间戳/坐标/量纲）
3. 六条共同规律 → 提炼成本片全局铁律（逐镜表的「前景/情绪色」两列由此来）
4. 这份规范放进 report，**先于任何画面代码**

## 并排自查（渲染之后，≥2 轮）

每轮：关键帧与同功能对标帧**两两拼图对比** → 列毛病 → 改 → 重截同一时刻 → 确认改掉且没改坏别的。

遮住字幕自问三问（观众视角）：这是什么 / 它在干什么 / 我明白了什么——答得含糊就是没做好。

## 九项密度清单（逐项勾，全过才算完）

- [ ] 随机 5 帧每帧 ≥3 层内容
- [ ] 每帧 ≥2 层在动
- [ ] 逐词字幕中间态有帧证（能拍到「半亮半暗」）
- [ ] 每镜微文案齐全（含英文译文同屏验证）
- [ ] 硬切白闪与 impact 对齐（抽帧确认恰 1 帧）
- [ ] 色彩情绪线可感知
- [ ] 元素种类未超「线·光·点」
- [ ] 每句字幕同屏 ≥2.5s（抽帧计时验证）
- [ ] 数据出处清单逐条核过

## 讲解设计（借自 vkf 的三条，防「配图不是讲解」）

1. **先找形象，再写文案**：每个概念找到外行认得的东西来演它；画不出的句子，改句子
2. **主体长得像它本身**：红细胞就是中间凹的圆盘，不是「一个圆加标签」；点线圈柱框不算
3. **动词真的发生**：「砍掉一半」就盖住一半，「粘住」就真的卡上去；数是算出来的
4. 提问、命名、结论、出处**不配新画面**——大约每五句有一句留白，字幕本身是事件

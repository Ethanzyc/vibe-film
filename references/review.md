# 验收与审片（Step 8）：两件事，分开做

| | 技术检查 | 审片 |
|---|---|---|
| 判断什么 | 文件对不对：解码/尺寸/帧率/时长/帧数/音轨/黑帧/响度 | 好不好看、讲没讲清、达没达成五问 |
| 谁来判 | 程序（ffprobe/抽帧脚本，PASS/FAIL） | 执行侧先写观察，**用户终审** |
| 结果 | 任何 FAIL 不能交付 | 已知问题如实告诉用户 |

**自己验的不能代替用户看片。** 执行侧看到的是抽帧图，不是真正播放的视频，也听不到声音——审片记录是帮用户更快看片，不是替用户下结论。**没验的项列 NOT CHECKED，不算验收通过。抽样跑的检查（抽了部分镜/部分帧/quick 模式）结论必须标 `PARTIAL(范围)`，只有全量跑过才可写「全 PASS」——部分验证不许声称通过（学 anatomy：quick/--only 的结束态是 partial，永远不是 passed）。**

## 1. 技术检查清单

- [ ] ffprobe：尺寸/帧率/时长（±1.5 帧）/帧数（±2）/音轨齐全
- [ ] 黑帧：只允许分镜表指定的剧本性黑场（如结尾淡出）
- [ ] 响度：−15±1.5 LUFS，真峰值 ≤−1.5 dBTP
- [ ] 确定性：同 t 跨渲染序抽帧一致
- [ ] 字幕无漏字（抽帧验，字体子集最容易翻车）
- [ ] impact 白闪恰 1 帧钉在指定秒

## 2. 审片十项（逐项写观察，不适用写「不适用」）

| 项 | 看什么 |
|---|---|
| 开场 | 前 3 秒有没有钩住人的东西（第一帧不许黑屏） |
| 节奏与密度 | 每 10-15s 有没有转折；有没有无意空拍 |
| 讲解有效性 | 遮住字幕问三问：这是什么/在干什么/我明白了什么——答得含糊就是没做好 |
| 运动质感 | 每帧 ≥2 层在动（判语见 storyboard.md：动词动作优先，禁凑指标微动）；量口径：最长静止 ≤3s，≥3s 须是表内 HOLD 帧逐个复核；有没有整屏闪（粒子/噪点种子隔帧重掷） |
| 构图与可读 | 主体 ≥ 内容区 1/3 画高；扫光类特效 ≤2 镜头；双语字幕手机尺寸可读、停留 ≥2.5s |
| 数字口径 | 数字、单位、出处与事实清单一致？示意标了「示意」？倍数说法对（「9 倍」≠「到 9 倍」）？图表从 0 起吗、纵轴截断写明了吗？图上的数能算出画面说的结论吗？展开换镜后计数有没有从 0 重来？ |
| 记忆点 | 有没有一个清楚的记忆点（可手算的数/签名镜） |
| 风格一致 | 色彩情绪线走完没有；微文案密度掉没掉；有没有落进禁止清单 |
| 音画关系 | impact 与白闪对位；重击前留白 |
| 完成度 | 闪帧、穿帮、文字重叠、结尾收束（淡出/呼应） |
| 俗套对照 | 对照 storyboard.md 反 AI 味指纹清单逐条勾；换一个主题，这支片子的画面还能原样套上去吗？能=没有从主题出发 |

审片记录格式（台账内）：

```markdown
## 第 N 轮
技术检查：全 PASS（或列 FAIL）
审片观察：
- 开场：…  - 数字口径：…
最严重的 3 个问题：
1. [42.0s] 演算式字号低于铁律下限 → 提到 48px
重渲范围：seg3 39-45s
仍未解决（交付时告诉用户）：…
```

修完只重渲出问题的段；**同一问题三轮修不掉，回分镜表换做法（换镜头类型/换结构），别再磨**。

**版本留档 + 四态复验（2026-10-27 增，学 a2e QC 多轮报告）**：审片记录按轮存档 `qa/review-v1.md、review-v2.md…`（台账只放汇总）。下一轮开头对上一轮的每个问题逐条给四态结论——**已修 / 部分修 / 未修 / 引入新问题**（引入的新问题进本轮清单）；「改过了」不是状态，四态之一才算数。交付时把最后一轮 review 连同未解决项一起给用户。

## 3. 独立审片（宿主支持子代理时）

自己看了三遍看不出的问题，没参与制作的人第一眼就看出来。交付前派一个审片子代理：

- **给它**：抽帧图/关键处连续帧/字幕检查图 + 五问的「献给句」和禁止清单。**不给**代码、制作过程、自己的审片记录——防止跟着思路走
- **要它交回**：按严重度排序的问题清单（每条带时间码+看到了什么+猜的原因），以及**它最不确定的三处**
- **怎么用**：结论与自己的审片分开记录，修完让它复查，区分「旧问题修好」和「新发现」；它说「缺记忆点」这类创意判断转给用户

## 4. 常见问题处方笺（症状 → 原因 → 修法，实战提炼）

| 症状 | 原因 | 修法 |
|---|---|---|
| 全片像会动的 PPT | 分镜是一句话意图，无三层内容 | 回 Step 2 补九列表，禁带病渲染 |
| 主体是「圆圈加标签」 | 概念没找到可演的形象 | 回选题层找形象（红细胞≠圆圈）；点线圈框不算主体 |
| 画面整体卡顿 | canvas 变换 save/restore 不配对，变换泄漏冻帧 | 全文审计 save/restore 配对 |
| 元素颜色不对/发黑 | tint helper 只解析 hex，收到 rgb() 得 NaN，fillStyle 静默失效 | tint 通吃两种格式；NaN 单测 |
| 前一镜残影叠在后一镜 | render(t) 没完全重绘（半透明底） | 每帧 clearRect 全量重绘 |
| 某层突然全亮 | globalAlpha 在契约函数内被替换而非继承 | 显式传参 alpha |
| caret/文字消失 | 变量遮蔽（forEach 参数名撞外层字段）→ x=NaN | 重名排查；NaN 断言 |
| 字漏字/豆腐块 | 字体子集没含该字形 | gen-fonts 按全句重生成；出片前抽帧验 |
| 中文字幕被读成两眼 | 停留 <2.5s 或一句 >16 字 | 抽帧计时验证；拆句 |
| impact 和白闪错位 | 音频先定秒、画面渲染没按同一张秒表 | 音频与画面共用分镜表的秒数常量 |
| 两段 UI 同构不同款 | 分段契约只有文字没有基准截图 | 段 1 产基准截图，段 2..N 先读图再写码 |
| 整屏隔几帧闪一下 | 粒子/噪点种子隔帧重掷 | seeded hash(x,y,t)，种子跨帧稳定 |
| 结尾戛然而止 | 没有淡出/落版 | 剧本性淡出 ≥2s 或元素呼应收束 |
| 观众说「AI 味」 | 深色+居中大字+全片一种入场+无微文案 | 回九列表查微文案密度与逐词浮现中间态 |

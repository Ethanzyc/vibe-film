# 九列逐镜表（Step 2）——成片质量的全部来源

同一模型同一工具，线框级分镜出「会动的 PPT」，运动脚本级分镜追平对标执行层（实验实证：差距 60-70% 在分镜规格）。**这张表不许退化为一句话意图。**

## 写表前：三个候选结构

**第一个冒出来的想法往往是这个题材的陈词滥调。** 先用两三行各写一个候选结构（如：一次倒数 / 一次前后对比 / 一个不切镜头的长镜头 / 一条线的旅行 / 一次变成另一个），选中一个并写明理由，再进九列表。

## 反 AI 味指纹清单（画面与声音，可勾选）

- 深色背景+居中大字+所有元素一起淡入+紫蓝渐变加发光（无约束时的默认脸）
- 整片一种入场动画 / 每步都挂 ken burns 或光晕呼吸
- 机位全程不动；没有微文案层的「纯字幕视频」
- 配乐落到 A 小调四踩+每个重拍 impact+钟声落版（几支片像同一首歌）
- AI 视频感的通用指纹：一帧和前后两帧都不同（漏画层/空画面）——抽帧必查
- 对照法：换一个主题，这支片子的画面还能原样套上去吗？能=没有从主题出发

**扣分制（2026-10-27 增，学 OnlyShot cliche-detector）**：命中即记 **-1/处** 并写出替换方向（不许只删不加），同一指纹命中 ≥3 处 = FAIL 必须改：

| 指纹 | 替换方向 |
|---|---|
| 所有元素一起淡入 | 逐词/逐元素 stagger，或动词驱动的持续动作 |
| 整片一种入场动画 | 每镜按语义选（生长/点亮/形变/接管），同款 ≤1/3 镜头 |
| 每步挂光晕呼吸 / ken burns | 换「持续动词动作 + 落位停留」，静止要静得有意 |
| A 小调四踩 + 每拍 impact + 钟声落版 | 按 BGM 选曲决策树换和声路径；impact 只钉转折秒 |
| 深色 + 居中大字默认脸 | 主体偏离中心构图，光打在主角身上 |

**例外**：致敬/戏仿/组合创新可用指纹，须在分镜表注明意图并经制作人确认。**每季度复审**：新片踩到的新指纹追加，过时条目移入「已过时」备注。

## 硬规则

- 结构公式（顺序固定）：钩子(3s)→概念展开(2-3镜)→冷知识/数字自算→反转→金句×2→献给+文献卡(3s)
- 一分钟只讲一个概念；每句 8-16 字独立成帧（≤2 行），**每句指定一个金色重点词**
- 字幕停留 ≥2.5s（含英文同屏），换句对齐小节线
- 数字给「观众拿计算器能复现」的演算式；示意设定标 `示意 · ILLUSTRATIVE`
- 事实核查条款：文末数据出处清单逐条可溯源，写进成片文献卡——「一个年份写错，评论区全是挑错的」
- 文献卡收尾：出处 2-3 条 + 献给帧 + 首尾元素呼应（如 caret 闪烁→静止）

## 九列定义

| 列 | 要求 |
|---|---|
| 时间 | 3s 整倍数（小节线），如 `0-3` `21-24`；**真曲 BGM 时 = beats.py 网格拍线，写小数秒**（如 `0-1.695`），机审加 `--grid audio/beats.json`（2026-10-27 制作人拍板） |
| 镜头类型 | 从九型菜单选（见下） |
| 字幕中 | 一句 8-16 字 + ⟨重点词⟩ 标注 |
| 字幕 EN | 整句意译（不逐字直译），成片淡入 |
| 背景 | 远景层：流动的底（星场/网格/纸纹/晨光），永不满帧静止 |
| 中景 | 主体层：这一镜「演」的动作（动词真的发生） |
| 前景/微文案 | ≥1 处等宽微文案：时间戳/量纲/英文注脚/帧内 UI 仿真 |
| 转场 | match cut（主体形变）/白闪+impact/黑场 0.15s/光斑/粒子接管；**新画面首次露出的那一帧要落在拍上**——渐显/光圈类转场起点=拍点−reveal×时长（audio.md 落拍三公式） |
| 情绪色 | 全片色彩情绪路径上的位置（如 蓝→琥珀→红→金→晨金） |

## 九型镜头菜单（每型挂对标帧做锚）

1. **钩子帧**（0-3s 定生死）：场景剪影+一颗动元素+微文案时间戳；第一帧不许黑屏
2. **关系网络帧**（思维树模块）：中心节点→分支生长，20-30 个**都有含义**的标签，颜色随情绪渐变（白→琥珀→红），远端虚化
3. **介绍卡**：三字体层级（中文衬线主名+等宽元数据+外文斜体原典）+渐变分隔线
4. **粒子材料帧**：数千粒子聚成文字/图形再散开，背后失焦文字层做景深（抒情金句专用）
5. **数据可视化叙事帧**：计数器三件套（大等宽数字+下划线+刻度）、评分点阵、双语轴标签——图表长在场景里
6. **隐喻帧**：一条线/一个框带微型标签贯穿全屏——线即叙事；单光源锥形束
7. **金句帧**：≥72px，重点词金色，粒子/光斑接管转场
8. **献给帧**：两行逐词+文献卡淡入+首尾呼应
9. **具象锚点帧**（2026-10-27 增）：外行一眼认得的具象主体演主题事件。四个配方：①**UI 仿真**——微信气泡/收藏夹/终端窗，真实感来自像素级还原（判例《重构》收藏夹 UI 三段同构）；②**剪影人物**——纯 fill 路径+姿态叙事（立/举手/垂头/并肩），**禁五官与衣褶细节**（去脸判例），身高 ≥ 内容区 1/3；③**几何道具**——领奖台/奖牌/秤/门/墙，几何拼装+一层光；④**微缩场景**——2-3 件道具+单光源+一条规则线即成景（比特新语银牌帧=人形×2+台块×2+光锥+淘汰线，六件元素）。锚点必须挂在主题事件或反转上，不是装饰插图；动作要真的发生（气泡发出/剪影登上/淘汰线压过）

## 渲染技术选型（按镜选，允许混用）

**框架（裸写/Remotion）不影响画面**——影响画面的是渲染技术层。九型菜单的技术建议：

| 渲染技术 | 擅长 | 对应镜头型 |
|---|---|---|
| Canvas 2D（默认） | 粒子、文字、图表、几何 | 钩子/数据叙事/隐喻/金句/献给/关系网络 |
| DOM/SVG | 精致排版、路径描边（手绘感） | 介绍卡三字体层级、文献卡排印、线稿逐笔 |
| WebGL/着色器 | 光影质感、水面、体积光、辉光 | 光锥/单光源类隐喻帧（Canvas 画不出的「真光」） |
| Three.js | 3D 空间、星云、镜头穿行 | 3D 转场、体积粒子 |

**表现强度档位（L1 总开关；第 1 步「一次问清」由用户选定，本项目默认=极限）**

> 两个轴别混：**效果优先红线**管成本（方案按效果上限排，质量妥协判定一律不成立，token/渲染轮数不设限）——永远成立，不管辖档位；**档位**是创作选择（这支片要不要冲表现上限），每支片由用户定，不擅自假设。默认极限是 2026-10-25 制作人定调的本项目默认值，不是普适规则。

- **极限档（默认）**：能力展示镜**每片 ≥1-2 镜，强制**——全片的 money shot（通常是反转帧/金句帧/主题事件帧）必须冲到表现上限：真刚体物理（碎块碰撞堆叠）、着色器光效（体积光/丁达尔）、千级粒子奇观（聚散成文字/形体）、一镜长镜头运镜。**判据：「人类动效师按这个预算做不出来或做不起，只有 AI 代码动画做得到」——这正是「体现 AI 能力」的定义**
- **标准档**：能力展示镜建议 ≥1 镜，挂反转帧或金句帧；其余纪律同极限档
- **收敛档**：能力展示镜 0-1 镜，且只允许挂主题事件帧（全片语义最高点）；克制做到极致同样是效果优先

三档通用的镜头分层：

- **风格化镜（多数叙事镜）**：有质感的模拟，密度在九列三层底线之上不设上限
- **示意图解镜（仅限节奏过渡）**：只用于呼吸/留白帧（每五句一句的「不配新画面」镜头），不作默认

**夸张的纪律**（夸张≠堆砌，极限/标准档适用）：①能力展示镜必须有内容理由——挂在反转/金句/主题事件的语义上，不是炫技插入（判据不变：这个镜头的物理/光效是不是内容本身）；②夸张镜前后必须留呼吸，冷静镜垫场——没有低谷就没有高峰；③反 AI 味清单照常全勾（禁满屏光晕、禁所有元素同时动、禁密度无层次的闹）；④能力展示镜在第 5 步出 3-8s 无声样片请用户确认方向与夸张度——九列表审得到语义，审不到「墙到底怎么塌」。

**三问判断树**（每镜按序问，默认答案 Canvas 2D，答「是」才升级）：

1. 画的是「光的行为」吗？（光锥/体积光/水面反射/真实辉光——需要光的物理行为）→ 是则 WebGL/着色器
2. 需要三维空间或镜头自由运动吗？（多面体/环绕/真透视）→ 是则 Three.js
3. 是排版、文字或线稿吗？→ 是则 DOM/SVG
4. 都否 → Canvas 2D

**执行口径（效果优先下重述）**：①换技术=换时间（着色器实测慢一个量级：同 3s 画面 Canvas 7s vs 着色器 48s）——计入排期，**不作为降档理由**；②回退判据仅适用于示意图解镜；能力展示镜（极限/标准档）的判据反转为「**不够惊艳就升级**」（如《危墙》倒塌镜 wireframe 版=不够惊艳→matter.js 升级）；③写实镜头第四选项是不画——C 路线生素材垫底（比特新语《风》的海面/信天翁实证），真人实拍感才需要。

规则：①混用时风格契约不变（色/字/情绪线跨技术一致）；②九列表在镜头类型列标注「本镜换 XX」，并写进该段工单。

## 密度底线（全片铁律，自查清单的源头）

任何一帧 ≥3 层内容（背景流动/中景主体/前景文字），任何时刻 ≥2 层在运动；**视觉词汇双层**（2026-10-27 修订，销账见 field-notes）：

- **抽象场域**（背景/氛围/转场）：线、光、点/粒子——密度靠语义标签堆，不靠新增图形种类；永不满帧静止照旧
- **具象锚点**（中景主体，**每片 ≥1 个**）：外行一眼认得的具象物体/场景——UI 仿真（微信气泡/收藏夹）、剪影人物、几何道具（领奖台/奖牌/秤/门）、微缩场景。挂在主题事件或反转帧上，与能力展示镜天然同镜（比特新语银牌帧=光锥+剪影+淘汰线同台；对标证据 assets/contrast.md #4-6）。**剪影级可画，不要求写实、禁止向写实滑**——写实需求转生素材 C 路线或 iso-kit 等距路线（待实测）

每镜 ≥1 处等宽微文案（真实感来源）；色彩情绪线全片一条，至少一处可感知转折；光即叙事（光锥/单光源指向哪，观众看哪）。

**「在运动」的判语（2026-10-27 增，学 a2e 过静/过动双教训）**：运动指**有语义的持续动作**——字幕里的动词在屏上真的发生。找不到动词动作就让它静着，把预算花在落位停留上；**禁止为凑「≥2 层在动」的指标给静止物体加漂浮/呼吸微动**。过静（入场即停）与过动（落位即切）是同一枚硬币的两面：停顿只放呼吸帧，末拍必须稳。

**帧级量化锚点（审片十项的度量口径，2026-10-27 增，学 a2e composition-and-light）**：

- 主角高度 ≥ 内容区 1/3（图形 ≥170px / 大字 ≥96px @1080p）；天然细小的题材（细胞/芯片）配对照物或放大框，不许缩成标签
- 最长静止 ≤3s；≥3s 的静止必须是刻意呼吸帧，在分镜表标 `HOLD`，审片时逐个复核
- 末拍落位停留 ≥30 帧（1s@30fps，目标 30-45 帧）再离场；运镜不进末拍
- 扫光/光带扫过类「最贵特效」全片 ≤2 镜头，只打在主角身上（常态辉光不在此列；a2e 第五片 8 处扫光被观众嫌的反例）
